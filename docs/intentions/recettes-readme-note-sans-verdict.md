# Intention : aligner `docs/recettes/README.md` sur la note « sans verdict » dans la release

**Statut** : proposée le 2026-10-30 — limite du chantier « release allégée » (journal du 2026-10-30).

## Besoin

Depuis le chantier « release allégée », en mode `solo`, la note « sans verdict » d'une release directe est le corps de la release GitHub, sans branche ni PR (QUA-079, la note de recette de chaque version). `docs/recettes/README.md` dit encore qu'elle arrive par la PR.

## Existant

Relevé le 2026-10-30 : `docs/recettes/README.md` décrit la note « sans verdict » comme écrite par la branche dédiée et la PR. Le chantier ne pouvait pas le toucher : hors de son bloc scope.
