# Routine maintenance

Permanent sheet for small tasks that don't warrant a separate project (a
fixed typo, a small local adjustment noted in passing…). A topic that grows
or needs a decision becomes a normal project, listed in
`docs/projects/pending.md`.

The commit-time check refuses a code file that no sheet covers (scoping
reminder, blocking — `docs/ia-first.md`, section 7). For a small task, add
its path to the `cadrage` block below; a pattern that's too broad (`**`,
`scripts/*`) is refused — name the file or use a precise pattern.
