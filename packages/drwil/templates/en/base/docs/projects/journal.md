# Closed projects journal

Condensed summary of each `docs/projects/` card once its Status moves to
"done" (the whole card, not just one point among several of a card that
otherwise stays open). The detailed card is then deleted: no more full
history in plain text in the repository, but nothing is lost —
`git log --follow -- docs/projects/<card>.md` (or the closing commit/PR
cited below) retrieves the full text at any time.

Goal: keep `docs/projects/` light (active cards only) without sacrificing
traceability, which stays in git anyway. See the recipe
`docs/recipes/working-with-branches.md`, "Closing" section.

One entry per closed project, most recent last.
